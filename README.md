# Fortune Cookie for the Liquidated Trader

A single fortune cookie line for a crypto trader who has just been liquidated:

> "A windfall is coming your way — just the wind from your liquidated long, whistling through your empty wallet."

## Run it

```sh
python3 main.py
```

Writes the fortune line to `/output/entry.txt` (no trailing newline, UTF-8) and prints it to stdout.
